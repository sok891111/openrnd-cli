# iflow 크롤러

사내 iflow 웹사이트를 크롤링하는 스킬입니다. 외부 인터넷용 `web_fetch` 와 달리,
이 스킬은 **사내망(intranet)에서만 접근 가능한 iflow 사이트**를 Python 코드로 직접
크롤링합니다. 프록시/인증서/세션 등 사내 환경에 맞춘 처리가 필요하기 때문에
별도의 `script.py` 를 통해 동작합니다.

## 언제 사용하나

- 사용자가 iflow 사이트의 페이지나 데이터를 가져오길 원할 때
- 외부 `web_fetch` 로는 접근이 안 되는 사내 URL 을 크롤링해야 할 때

## 동작 방식

크롤링 로직은 이 스킬 폴더의 `script.py` 에 들어 있습니다.
`run_python` tool 로 해당 스크립트를 실행하세요.

```bash
python skills/iflow/script.py <URL>
```

- 첫 번째 인자로 크롤링할 iflow URL 을 전달합니다. (생략 시 기본 URL 사용)
- 스크립트는 페이지를 요청하고, HTML 을 파싱하여 결과를 JSON 으로 표준출력에 찍습니다.

## 워크플로우

1. 사용자에게 크롤링할 iflow URL 을 확인합니다. (없으면 기본값 사용)
2. `run_python` 으로 `skills/iflow/script.py` 를 실행하며 URL 을 인자로 넘깁니다.
3. 스크립트의 표준출력(JSON)을 읽어 사용자에게 필요한 형태로 정리해 전달합니다.
4. 실행이 실패하면(사내망 미연결, 인증 오류 등) 오류 메시지를 그대로 사용자에게 보여주고
   원인(예: VPN/사내망 연결 필요)을 안내합니다.

## 참고

- `script.py` 는 사용자가 직접 수정하여 파싱 규칙, 인증, 대상 셀렉터 등을 맞출 수 있습니다.
- 의존 패키지: `requests`, `beautifulsoup4`. 미설치 시 스크립트가 안내 메시지를 출력합니다.
